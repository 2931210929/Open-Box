# Open-Box v0.1.366

- 移动端“路由／连接／日志”改用文字页签；连接状态和日志操作移至右上角，减少工具栏行数。
- 代理页签统一采用设置页样式，PC 端补齐“策略／节点／订阅”图标，保留数量和选中动效。
- 连接设置中的 PC、移动端显示样式合并为一行，优化小屏间距与排列。
- 本次更新路由器端与 Docker；客户端继续使用最近正式版 0.1.362。
