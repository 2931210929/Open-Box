# Open-Box v0.1.362

- 修复 iOS 已连接 VPN 时，路由查询失败并可能导致 VPN 扩展退出的问题。
- 本地分流同步配置时，同时采用路由器当前的策略和手动节点组选择。
- 修复 WireGuard 节点预览失败，以及临时测速误用 FakeIP 导致的失败。
- 所有客户端的路由测试站点图标移到右侧，大小与搜索按钮统一。
