# Open-Box v0.1.361

- 修复 TUIC、Hysteria2 等节点导入时丢失证书指纹，保留证书身份校验。
- 修复 WireGuard 订阅的预共享密钥及 MTU 参数遗漏。
- 订阅管理和「代理 → 订阅」显示「登录／订阅／节点」模式标签。
- 连接样式分别保存 PC 端和移动端设置，默认均为卡片，移动端修改可生效。

路由器与客户端请同步更新。升级后刷新对应订阅，补回旧节点记录中丢失的参数。
