# Open-Box v0.1.369

- 修复路由器手机端设置页顶部内容被菜单遮挡的问题，兼容顶部安全区与屏幕宽度切换。
- 修复跳转到指定设置项时，标题被顶栏盖住的问题。
- 提升深色主题下状态标签、说明文字、输入提示及页签文字的可读性，手机和 PC 统一生效。
- 本次更新路由器端与 Docker；客户端继续使用 0.1.367。
