# Open-Box v0.1.365

- 将连接、日志和运行规则合并为“连接”，通过“路由／连接／日志”页签切换，支持记住当前页签及兼容旧链接。
- 桌面端顶部合并为一行；移动端页签独占一行，工具栏适配小屏，并统一首张卡片的安全间距。
- 本次更新路由器端与 Docker；客户端继续使用最近正式版 0.1.362。
